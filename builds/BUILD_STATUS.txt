🚀 DEPLOYMENT INSTRUCTIONS

Android:
  1. adb install -r builds/Krida-android-debug.apk
  2. Open app, go to game screen
  3. Toggle "Online" (top-right)
  4. Tap "Quick Match" button

iOS:
  1. Xcode: Open ios/Krida.xcodeproj
  2. Connect iPhone via USB
  3. Select device and tap Play button
  4. Trust app: Settings > General > VPN & Device Management
  5. Open app, go to game screen
  6. Toggle "Online" (top-right)
  7. Tap "Pencarian Cepat" button
